# **App Name**: PictoPoem

## Core Features:

- AI Poem Generation: Generate poems based on uploaded or selected images using a generative AI tool. The LLM will decide when to incorporate visual elements from the image into the poem.
- Image Input: Allow users to upload images from their device or use a sample image.
- Poem and Image Display: Display the generated poem alongside the input image.

## Style Guidelines:

- Primary color: Soft green (#A7D1AB) to evoke nature and creativity.
- Secondary color: Light gray (#E5E5E5) for backgrounds and neutral elements.
- Accent: Warm orange (#FFB347) for call-to-action buttons and highlights.
- Clean and readable font for poem text.
- Simple and intuitive icons for actions like upload, generate, and share.
- Clean and modern layout with the image and poem prominently displayed.
